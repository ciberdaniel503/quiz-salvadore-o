# 🇸🇻 Quiz de Reto Salvadoreño

Proyecto web interactivo de preguntas sobre la cultura y los conocimientos de El Salvador, desarrollado con tecnologías web.

## 🎯 Objetivo

Crear una experiencia de preguntas y respuestas que permita explorar y poner a prueba los conocimientos sobre El Salvador mediante una aplicación web.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura de la aplicación.
- **CSS3:** estilos y presentación visual.
- **JavaScript:** lógica e interactividad del cuestionario.

## 📚 Tema del proyecto

El cuestionario está enfocado en preguntas relacionadas con la cultura y los conocimientos de El Salvador.
